## File Map

### Primary Execution (start here every session)
| File | Purpose |
|------|---------|
| `RUN_THE_SLATE.md` | **One startup sequence. One market list. One output format.** |
| `config/rules.json` | Machine-readable thresholds: calibration, multipliers, gates, park factors |
| `scripts/validate_slate_final.py` | Pre-analysis gate — fails if any game missing required fields or marketLedger incomplete |

### Reference Documents (define math/rules; never execution order)
| File | Purpose |
|------|---------|
| `RULES.md` | All 83 betting rules with T1/T2/T3 tier definitions |
| `MODEL_CORE.md` | Probability engine, sizing math, calibration, CLV formula |
| `SLATE_WORKFLOW.md` | Session workflow detail and output format examples |
| `DATA_SOURCES.md` | Odds architecture, data field definitions, fallback chain |

### Bet Records
| File | Purpose |
|------|---------|
| `bets.json` | Authoritative bet ledger — flat JSON array, parse directly |
| `BET_LOG.md` | Human-readable log — auto-generated by update-clv.yml, never edit |
| `clv_update.py` | CLV settlement script |

### GitHub Actions
| File | Status | Purpose |
|------|--------|---------|
| `fetch-slate.yml` | ✅ Production | Fetches all slate data, writes data/ files |
| `update-clv.yml` | ✅ Production | Settles bets, computes CLV |

### Documentation
| File | Purpose |
|------|---------|
| `docs/GITHUB_WRITE_GUIDE.md` | How to write files to repo from Claude |
| `docs/MODEL_HISTORY.md` | Version changelog |

### Data Files (written by Actions — never commit manually)
| File | Contents |
|------|---------|
| `data/slate.json` | Full slate: odds, pitchers, bullpen, projections |
| `data/pitchers.json` | Confirmed starters |
| `data/teamstats.json` | Team hitting stats, rolling R/G |
| `data/weather.json` | Park weather |
| `data/meta.json` | Fetch timestamp — verify before using |
| `data/kalshi_search.json` | All Kalshi market prices indexed by event_ticker |

### Archived (not current — do not use as instructions)
| File | Reason |
|------|--------|
| `archive/RULES_INDEX.md` | Superseded by config/rules.json |
